## 新发现的沙箱坑（重要）
- Hermes 沙箱 secret-redaction 不仅破坏 bash 里的 $(...) 命令，
  还会改写 execute_code Python 脚本中的「token 样」字面量（如 UUID、`token=***
  表现：API 收到被篡改的值 → 假性 400/失败（本次 id=12 token 被误判无效即此因）。
- 排查四步：① 服务器端 node 直连 DB 复现查询 ② lsof/proc 确认同一 DB 文件
  ③ 外部写他表验证 WAL 可见性（排除旧快照）④ 服务器本地 curl 自调 API（定位到客户端侧）。
- 规避：敏感值不做脚本字面量——运行时 subprocess 从 DB/文件读取后直接使用。
- 出网代理仍会改写请求体明文 "admin123"，继续用运行时拼接（"admin"+"123"）。
